# 📚 Sistema de Generación de Bibliografía para LaTeX

## Comparación de Soluciones

### 🔴 Solución Original (Compleja)
- ✅ Completa y profesional
- ❌ Requiere MySQL
- ❌ Requiere conocimientos técnicos
- ❌ Más de 10 dependencias

**Para quién**: Investigadores con experiencia técnica

---

### ✅ Solución Simplificada (Nueva)
- ✅ Sin MySQL
- ✅ Solo requiere API Key de Gemini (GRATIS)
- ✅ Script .bat para ejecutar con doble clic
- ✅ Instrucciones en 5 pasos

**Para quién**: Compañeros de la Maestría sin conocimientos técnicos

---

## 📁 Archivos Incluidos

### Solución Compleja (para ti):
- `procesar_pdfs_academicos.py` - Procesador con MySQL
- `consultar_documentos.py` - Sistema de consultas
- `generar_bibliografia.py` - Generador BibTeX
- `consultas_sql_utiles.sql` - Queries SQL
- `README_SISTEMA_DOCUMENTOS.md` - Documentación completa

### Solución Simplificada (para compañeros):
- `generar_bibliografia_simple.py` - Script principal
- `GENERAR_REFERENCIAS.bat` - Ejecutable
- `GUIA_BIBLIOGRAFIA.md` - Manual de usuario

## 🎯 Cuándo Usar Cada Solución

### Usa la Solución Compleja si:
- ✅ Tienes cientos de PDFs
- ✅ Necesitas búsqueda en base de datos
- ✅ Quieres consultas SQL avanzadas
- ✅ Tienes MySQL instalado

### Usa la Solución Simplificada si:
- ✅ Tienes 20-100 PDFs
- ✅ Solo necesitas generar BibTeX
- ✅ No tienes conocimientos técnicos
- ✅ Quieres algo rápido y simple

---

## 💡 Ventajas de la Nueva Solución

1. **Sin MySQL**: No requiere configuración de bases de datos
2. **Solo 2 dependencias**: `google-generativeai` y `pymupdf`
3. **Instalación automática**: El .bat instala todo automáticamente
4. **Gratis**: Usa plan gratuito de Gemini (60 req/min)
5. **Plug & Play**: Solo necesitas tus PDFs y una API key

---
