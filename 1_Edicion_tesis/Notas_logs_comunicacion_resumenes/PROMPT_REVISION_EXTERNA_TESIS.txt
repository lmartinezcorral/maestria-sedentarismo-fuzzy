II. MARCO DE REFERENCIA PARA LA EVALUACIÓN
================================================================================

GUÍAS BASE (aplicar estrictamente):

A. REDACCIÓN CIENTÍFICA (Schmelkes - "Chispas")
   - Claridad: Oraciones cortas (≤25 palabras), estructura S-V-C
   - Concisión: Eliminar redundancias, palabras huérfanas
   - Precisión: Verbos específicos (evitar: hacer, dar, tener, haber)
   - Fluidez: Conectores lógicos, transiciones entre párrafos
   - Voz activa predominante (≥70% del texto)
   - Gerundios SOLO para simultaneidad real
   - Evitar "que" múltiples en misma oración

B. FORMATO ACADÉMICO (APA 7ª Edición)
   - Sangrías: Primera línea 1.27 cm (excepto título de sección)
   - Interlineado: 1.5 o doble
   - Niveles de títulos correctos (1-5)
   - Citación autor-fecha: (Apellido, año) o Apellido (año)
   - Números: <10 en letra, ≥10 en cifras (excepto medidas/datos)
   - Tablas y figuras: numeración, título descriptivo, notas

C. RIGOR METODOLÓGICO (Sampieri 6ª Ed. + OPS 2008)
   - Coherencia: Pregunta → Objetivos → Hipótesis → Métodos → Resultados
   - Justificación: Brecha de conocimiento clara y documentada
   - Población: Criterios inclusión/exclusión explícitos
   - Variables: Definición operacional precisa
   - Análisis: Pruebas estadísticas apropiadas para tipo de dato
   - Ética: Consentimiento informado, comité de ética
   - Reproducibilidad: Software, versiones, parámetros detallados

D. CONTRIBUCIÓN CIENTÍFICA (Estándares Q1)
   - Originalidad: Aporte novedoso al campo
   - Relevancia: Impacto potencial en salud pública/clínica
   - Comparación: Posicionamiento vs. literatura existente
   - Transparencia: Limitaciones reconocidas honestamente
   - Proyección: Líneas futuras de investigación

V. CRITERIOS DE CALIDAD ESPECÍFICOS (CONTEXTO DEL PROYECTO)
================================================================================

PROYECTO: "Modelo de Evaluación del Comportamiento Sedentario mediante 
          Lógica Difusa y Datos Biométricos"

CONCEPTOS CLAVE A VALIDAR:

1. POBLACIÓN Y DISEÑO
   ✓ N=10 usuarios, seguimiento longitudinal (media: 133.7 semanas/usuario)
   ✓ Paradigma BYOD (Bring Your Own Device) - Apple Watch
   ✓ Datos retrospectivos de vida libre (no laboratorio)
   ✓ Total: 1,337 semanas válidas agregadas

2. VARIABLES DERIVADAS (verificar definición operacional):
   • Actividad relativa (pasos/hora de uso normalizado)
   • Superávit calórico basal (energía activa / TMB)
   • Delta cardíaco (FC caminar - FC reposo)
   • HRV-SDNN (variabilidad frecuencia cardíaca)

3. METODOLOGÍA HÍBRIDA
   ✓ Clustering K-Means (k=2) → Ground Truth operativa
   ✓ Sistema Inferencia Difusa Mamdani (5 reglas)
   ✓ Validación Leave-One-User-Out (LOUO)
   ✓ Análisis de ablación para evaluar contribución de variables

4. MÉTRICAS ESPERADAS (verificar reporte completo):
   • F1-Score global: 0.780 ± 0.167
   • Precisión: 0.800
   • Sensibilidad (Recall): 0.783
   • Kappa de Cohen: 0.56
   • Índice Silhouette (clustering): 0.232

5. HALLAZGO CLAVE (debe estar bien argumentado):
   "Paradoja HRV": Variable sin poder discriminatorio univariado (p=0.24,
   d=0.21), pero CRÍTICA en modelo multivariado (ablación: -51% F1-Score).
   Evidencia de modificación de efecto y supresión estadística.

6. LIMITACIONES A RECONOCER:
   ✓ N pequeño (10 usuarios, aunque 1,337 observaciones temporales)
   ✓ Ground truth operativa (no estándar de oro como calorimetría)
   ✓ Heterogeneidad tecnológica (Apple Watch Series 3-9)
   ✓ Población específica (adultos jóvenes universitarios, Chihuahua)
   ✓ Periodo incluye pandemia COVID-19 (2020-2023)

PREGUNTAS CRÍTICAS A RESPONDER EN CADA CAPÍTULO:

• INTRODUCCIÓN: ¿Se justifica claramente por qué lógica difusa > ML clásico
  para este problema? ¿Se establece brecha de conocimiento específica?

• MÉTODOS: ¿Son replicables los pasos? ¿Se especifican versiones de software,
  semillas aleatorias, parámetros? ¿Está el flowchart de preprocesamiento?

• RESULTADOS: ¿Se reportan métricas completas (no solo F1)? ¿Se muestra
