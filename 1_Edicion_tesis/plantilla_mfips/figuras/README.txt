==========================================================
CARPETA DE FIGURAS
==========================================================

INSTRUCCIONES:

1. Guarda todas tus imágenes aquí (gráficas, diagramas, fotos)

2. Formatos recomendados:
   - .PNG para capturas de pantalla, fotos
   - .PDF para gráficas vectoriales (mejor calidad)
   - .JPG para fotos (menor tamaño)

3. Nombra tus archivos de forma descriptiva:
   ✅ BIEN: "arquitectura_sistema.png"
   ✅ BIEN: "grafica_resultados_experimento1.pdf"
   ❌ MAL: "img1.png"
   ❌ MAL: "Captura de pantalla 2025-01-15.png"

4. Consejos:
   - NO uses espacios en nombres (usa guiones bajos: _ )
   - NO uses acentos ni ñ en nombres de archivo
   - Mantén nombres en minúsculas
   - Comprime imágenes grandes (max 2-3 MB por imagen)

5. Organización opcional:
   Si tienes muchas figuras, puedes crear subcarpetas:
   
   figuras/
      capitulo1/
      capitulo2/
      capitulo3/
      diagramas/
      graficas/

   Y luego referenciar así:
   \includegraphics{figuras/capitulo2/grafica1.png}
